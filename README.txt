DriverTalk V1.8 – Carletti testversion · separat repository Drivertalk-1

Indhold: 12 chaufførsprog, faste oversatte standardsætninger og chaufførvisning.
Ingen mikrofon, talegenkendelse, fri oversættelse, login, database eller bookingnummerindtastning.
Afspilning er kun mulig, hvis enheden understøtter det valgte sprogs stemme.
Oversættelserne er udkast, især sikkerhedstekster må ikke bruges uden sproglig godkendelse.

SÅDAN UDGIVES APPEN
1. Download ZIP-filen og pak den ud på computeren.
2. Åbn GitHub-repository: https://github.com/johnfinmann-ctrl/Drivertalk-1
3. Upload disse SEKS filer direkte i repositoryets rod (ikke en mappe og ikke ZIP-filen).
4. Commit changes.
5. Settings > Pages > Deploy from a branch > main > /(root) > Save.
6. Når GitHub Pages er aktiv, åbn: https://johnfinmann-ctrl.github.io/Drivertalk-1/

Hvis der vises 404: Kontrollér at index.html ligger i rodmappen, og at Settings > Pages viser aktiv publicering.
Det oprindelige repository drivertalk ændres ikke.
