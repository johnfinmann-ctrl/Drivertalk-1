DriverTalk V1.9 – Carletti pilot til repository Drivertalk-1

Indhold: 12 sprog, faste oversatte spørgsmål inkl. kølemaskinens indstillede temperatur, hurtige chaufførsvar og temperatur i °C på samme enhed.

Ingen mikrofon, ingen database, ingen live-synkronisering, intet login. Temperaturinput findes kun i den åbne visning og gemmes ikke. Ved separat telefon skal chaufføren vise svarskærmen til lagermedarbejderen.

UPLOAD: Udpak ZIP og upload ALLE seks filer direkte i rodmappen på GitHub repository Drivertalk-1. GitHub Pages: main / (root).

VIGTIGT: Oversættelser er udkast og skal gennemgås af sprogkyndige før officiel brug, særligt sikkerhedsbeskeder. Ingen bekræftet browser-/iPhone-test gennemført.
